──────────────────────────────────────────────────────────────────
  METHOD 2: One Command at a Time
──────────────────────────────────────────────────────────────────

flutter clean

Remove-Item pubspec.lock -Force

flutter pub get

flutter pub upgrade

flutter run -d chrome

──────────────────────────────────────────────────────────────────
  METHOD 3: Use The Script
──────────────────────────────────────────────────────────────────

.\fix_and_run.ps1

Then:

flutter run -d chrome

──────────────────────────────────────────────────────────────────

.\fix_and_run.bat
